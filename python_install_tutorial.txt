=================================================
初心者向け:Macで安全にPythonをインストールする方法
=================================================

このチュートリアルでは、Macに安全にPythonをインストールする
2つの方法を紹介します。

  方法A:Python公式サイトからインストール(初心者におすすめ)
  方法B:Homebrewを使ってインストール(少し慣れている人向け)

どちらの方法でも構いませんが、初めての方は「方法A」がシンプルで
わかりやすいです。


-------------------------------------------------
■ 事前に知っておきたい注意点(安全のために)
-------------------------------------------------

1. Pythonは必ず「公式サイト」からダウンロードしてください。
   公式サイト: https://www.python.org/

   検索結果に出てくる非公式のサイトや、広告経由のリンクから
   ダウンロードするのは避けましょう。ウイルスや不要なソフトが
   混入しているリスクがあります。

2. Macには「システムPython」が最初から入っていることがありますが、
   これはmacOS自体が使うためのものなので、絶対に削除したり
   上書きしたりしないでください。自分用には別途新しいPythonを
   インストールします。

3. ダウンロードしたファイルは「.pkg」形式です。インストーラーを
   実行する前に、ダウンロード元のURLが
   「https://www.python.org」であることを必ず確認しましょう。


-------------------------------------------------
■ 方法A:公式サイトからインストール
-------------------------------------------------

【手順1】ブラウザで以下にアクセスします。
   https://www.python.org/downloads/

【手順2】「Download Python 3.x.x」という黄色いボタンをクリックし、
   Mac用のインストーラー(.pkgファイル)をダウンロードします。
   ※ 数字(3.x.x)は現時点の最新バージョンが自動的に表示されます。

【手順3】ダウンロードした .pkg ファイルをダブルクリックします。

【手順4】インストーラーの指示に従って「続ける」→「同意する」→
   「インストール」と進みます。
   ※ Macのログインパスワードの入力を求められることがあります。
     これは正常な動作です。

【手順5】インストールが完了したら「閉じる」をクリックします。


-------------------------------------------------
■ 方法B:Homebrewを使ってインストール
-------------------------------------------------

Homebrewは、Mac用のパッケージ管理ツールです。
すでにHomebrewを使ったことがある方向けです。

【手順1】ターミナル(Terminal)を開きます。
   (Launchpad → 「その他」→「ターミナル」)

【手順2】Homebrewがインストール済みか確認します。
   以下をターミナルに入力してEnterキーを押します。

       brew --version

   バージョン番号が表示されればインストール済みです。
   何も表示されない、またはエラーが出る場合は、
   Homebrew公式サイト(https://brew.sh/)の手順に従って
   先にHomebrewをインストールしてください。

【手順3】以下のコマンドを入力してPythonをインストールします。

       brew install python

【手順4】インストールが終わるまで待ちます
   (インターネット環境によって数分かかることがあります)。


-------------------------------------------------
■ インストールできたか確認する方法
-------------------------------------------------

【手順1】ターミナルを開きます。

【手順2】以下のコマンドを入力します。

       python3 --version

【手順3】「Python 3.x.x」のようにバージョン番号が表示されれば
   インストール成功です。

   もし「command not found」と表示される場合は、
   インストールがうまくいっていない可能性があります。
   その場合は、方法Aの手順をもう一度確認してみてください。


-------------------------------------------------
■ おまけ:安全にプログラムを試すための「仮想環境」
-------------------------------------------------

Pythonでいろいろなライブラリを試していると、環境が
ごちゃごちゃになることがあります。それを防ぐために
「仮想環境(venv)」という仕組みを使うのがおすすめです。

【作成方法】
   任意のフォルダに移動してから、以下を実行します。

       python3 -m venv myenv

【有効化する方法】

       source myenv/bin/activate

   ターミナルの先頭に (myenv) と表示されれば成功です。
   この状態でインストールしたライブラリは、このmyenv
   フォルダの中だけに閉じ込められるので、他の環境に
   影響を与えません。

【終了する方法】

       deactivate


-------------------------------------------------
■ まとめ
-------------------------------------------------

・Pythonは必ず公式サイト(python.org)か、Homebrewなどの
  信頼できる方法でインストールする
・システムに最初から入っているPythonは触らない
・インストール後は「python3 --version」で確認する
・慣れてきたら仮想環境(venv)を使うとより安全

以上で、Macへの安全なPythonインストールは完了です。
お疲れさまでした!
