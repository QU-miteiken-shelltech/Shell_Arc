# shellarc_core

### *For the English version, see [README.md](./README.md).*

アニメ・映像制作の現場にありがちな「あのファイルどこ？」「これ誰が承認したっけ？」「スプレッドシートの更新忘れてた…」を、まるごと自動化するライブラリです。

Discordボット・Slackボット・Webダッシュボード・CLIなど、好きな見た目のツールに組み込んで、裏側の面倒な作業はぜんぶ `shellarc_core` に任せられます。

---

## 🎬 これで何ができるの？

- **📁ファイルを探し回らなくていい**
  誰が・いつ・どのバージョンを提出したかが自動で記録されます。「`_final_v3_本当の最終版.blend`」を共有ドライブの奥から発掘する日々とはお別れです。

- **✅承認したら、あとは全部自動**
  監督がOK/NGを押すだけで、進捗管理スプレッドシートのステータスやセルの色まで勝手に更新されます。台帳を手作業で書き換える人はもう不要です。

- **🖼️絵コンテもまとめて管理**
  Notionを直接いじらなくても、絵コンテ画像のアップロードや進捗更新をお任せできます。

- **🔄同じ素材をカット間で使い回せる**
  一度作った背景やモデルを、別のカットでも参照・複製できます。しかも普通の提出と同じレビューの流れにちゃんと乗ります。

- **📦大きいファイルも気にせず扱える**
  小さいファイルはすぐ使えるパスで、大きいファイルは自動的にダウンロード用リンクに切り替わります。

- **📜履歴はいつでも一発検索**
  「このカット、これまで何回リテイクした？」にすぐ答えられます。ダッシュボードや監査ログにもそのまま使えます。

---

## ✨ 何が特別なの？

- **🔌見た目は自由、中身はシステムにお任せ**
  Discordでも、Slackでも、Webアプリでも、呼び出す関数はほぼ同じ。裏側でGit・ストレージ・スプレッドシート・Notionを連携させる面倒なロジックは、すでに解決済みです。

- **🎯「言った/言わない」が起きない**
  Gitを唯一の正解として、他のツール（スプレッドシートなど）はすべてそこから自動で反映される仕組みです。「スプレッドシート上は承認済みなのに、実際のファイルは未レビュー」みたいな食い違いが起こりません。

- **🔍エラーで悩まない**
  起きたエラーが「使い方の問題（そのまま画面に出せるメッセージ付き）」なのか「システム側の不具合（運用担当者に連絡すべきもの）」なのかが、最初から仕分けされています。

- **🚀すぐ試せる標準セット付き**
  コードを1行も書かなくても、Discordボット一式（提出・承認・履歴照会などのコマンド完備）がそのまま使えます。もちろん自分だけのフロントエンドを作ることもできます。
